# Interview

A Claude Code skill for deep, exhaustive requirements gathering. Reads existing SPEC.md, interviews about technical implementation, UI/UX, edge cases, tradeoffs, and concerns. Continues until complete, then hands off to create-spec or create-plan.

## When to use

Trigger phrases: "interview me", "fill out the spec", "spec this out", "deep dive on requirements", "help me think through this".

## What it covers

- **When to Use**: Situations that call for deep requirements gathering
- **Workflow**: How the interview progresses from broad to specific
- **Anti-patterns**: Common interviewing mistakes
- **Example Interview Flow**: A real-world interview walkthrough

## Usage

```
/interview
```

Pairs well with `create-spec` (to structure output) and `create-plan` (to turn requirements into tasks).
