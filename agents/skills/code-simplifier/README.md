# Code Simplifier

A Claude Code skill that simplifies and refines existing code for clarity, consistency, and maintainability while preserving all behavior.

## When to use

When asked to "simplify code", "clean this up", "refactor for readability", "reduce complexity", or to polish recently modified code without changing functionality.

## What it covers

- **Guardrails**: Rules to prevent behavior changes during simplification
- **Workflow**: How to approach code simplification systematically
- **Quality Bar**: What "simplified" means in practice

## Usage

```
/code-simplifier
```
