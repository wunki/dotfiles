# Tech Docs Writer

A Claude Code skill that transforms complex codebases into clear, accurate documentation. Follows the principles of William Zinsser's "On Writing Well": simplicity, clarity, brevity, and humanity.

## When to use

When creating or updating README files, API docs, architecture documentation, and user guides.

## What it covers

- **Core Principles**: Verification first, simplicity, cut clutter, unity, be human
- **Documentation Standards**: Structure, code examples, language, formatting
- **Process**: Understand audience, review code, find the lead, draft, rewrite, verify
- **Quality Checklist**: Validation criteria before shipping docs
- **What You Avoid**: Passive voice, jargon, hedging, filler, walls of text
