# Ask Questions If Underspecified

A Claude Code skill that clarifies requirements before implementing code. Asks focused questions to fill gaps in scope, constraints, or acceptance criteria.

## When to use

When a request is vague, ambiguous, has multiple interpretations, or when you need to understand "what does done look like?" before starting work.

## What it covers

- **Goal**: What the skill achieves and when it activates
- **Workflow**: How to structure clarifying questions
- **Question templates**: Ready-to-use patterns for common ambiguity types
- **Anti-patterns**: Common mistakes when gathering requirements

## Usage

```
/ask-questions-if-underspecified
```

Or triggered automatically when Claude detects underspecified requirements.
